Install Khemet

Khemet is a Fabric mod for Minecraft 1.21.4. No release jar is published yet, so you build it.

Words used here: a mod is an add-on for the game; a jar is the mod’s file; Fabric is the program that loads mods; an operator is a player allowed to use admin commands.

You need

  • Minecraft Java Edition 1.21.4 (not Bedrock)
  • Fabric Loader 0.16 or later, and Fabric API
  • Java 21 and Gradle 8 (the repository has no Gradle wrapper)

Build

git clone https://github.com/SolutionsAsService/minecraft-khemet
cd minecraft-khemet
gradle build
# the jar is in build/libs/khemet-0.1.0.jar

Copy the jar into your mods folder and start the game. The server log line Khemet loaded: 6 potions, 6 brewing recipes, 0 unknown effects skipped; 23 blocks, 6 gods, 5 creatures confirms the registration.

Commands

Commands
/khemet favorYour favor and stage with each god.
/khemet offer <god>Operators: offer the item in your hand to a god (the same code the altar runs).
/khemet sandstorm start|stopOperators: start or stop a sandstorm.

Status

Seen in a running Minecraft 1.21.4 game:

  • Builds on Fabric Loom 1.11.8 and Gradle 8, and loads on a Fabric 1.21.4 dedicated server; a client joined and rendered every page of photographs here.

Not yet tested:

  • Other platforms and mods: it is built and tried only on Fabric 1.21.4 with Fabric API.
  • A published release jar.
